## 4. 门禁与脚本（核心，别重写，直接用）

所有脚本在 `silver-pulse/scores_draft/rework/`。

### 4.1 硬门禁 check_single.py（V4）
最新版门禁，规则：
- **R1**：recommend 是单字符串（非 dict）
- **R2**：字数 60-240（建议80-160）
- **R3**：禁模板签名句（"信号偏弱…切入行业媒体赛道"等）
- **R4**：落到本企业事实（含 name_cn 或任一 tag_l2 锚点）
- **R5**：单条命中四维度词族（信号/信息量/差异化/可复制）
- **R6**：desc_cn ≥80字
- **R7**：silver_reason ≥30字
- **R8**：payor_model 用规范词表（11项，含"B端机构采购+个人自费"）
- **R10**：跨企业去重 >0.5 打回（LCS + trigram 双算法）
- **R-field-dedup（V4新增）**：查6组字段（desc/silver/highlights×每条/funding），阈值10/8字
- **R-integrity（V4新增）**：前后半段赛道关键词不能完全不相交（防拼接串内容）
- **R-novelty（V4新增）**：与任一字段重叠≤70%
- **R-name**：禁企业名（列表已有）
- **R-jargon**：禁技术黑话
- **R-noabs**：禁"国内空白/缺乏/尚无/独家垄断/无竞品"

用法：
```bash
python check_single.py draft_#XXXX.json          # 单文件自校
python check_single.py --batch batch_src.json     # 批量校验
```

## 6. 推荐理由写作标准

**形态**：1 个字符串，覆盖四维度。不写企业名、不抄 desc_cn/投融资、大白话、不写"国内空白"。

**四维度怎么落**（编辑判断，不是填空）：
- 信号：为什么现在是热点（融资/收购/上市/政策/中标/合作/收缩/亏损…）
- 信息量：可查证公开数据（财报/营收/用户量/门店数/专利/临床/融资额…）
- 差异化：和别家不同（模式/壁垒/黏性/定位/首创/高频…）
- 可复制：国内怎么借鉴（可复制/借鉴/对标/思路/打法可学…）

**好样例**（Oak Street #0565）：
> 被Optum收购的老年连锁诊所。核心打法：用标准化预防护理+社区诊所做老年获客入口，高医患比和社交化诊所有效黏住慢病老人。国内险企可借鉴其"诊所即流量入口"模式，但按人头付费的医保结构难直接照搬。

## 12. 自迭代机制（最重要的一条）

- 发现某类坏写法没被抓 → 往 `check_single.py` 的 BANNED/JARGON/ABSOLUTE/DIM_*/FIELD_DEDUP 加词。

> 记忆会出错，门禁不会。把每一条"下次别犯"变成代码里的一行 `if ... issues.append(...)`。
