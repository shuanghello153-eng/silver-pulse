## 二、推荐理由写作铁律（11 条，对应门禁 R1–R10；任何一条不满足=打回）

1. **单字符串**：`recommend` 是 1 段话（可换行/用序号分层），不是 dict、不是三版。
2. **字数 70~220**（去空白）：太短没信息量，太长必啰嗦。字数是地板，**质量看下面几条**。
3. **禁模板套话**：不得出现"复制需结合本地资源""国内宜学其思路而非形态""轻模式易复制…""切入XX赛道"等生成器套话。每句必须落到**这家企业具体事实**（业务/融资/模式/数据/地区）。
4. **落到本企业事实**：含数字（融资额/门店数/用户量…）或任一 `tag_l1/tag_l2` 词。放哪家都成立的泛泛之谈一律毙。
5. **覆盖四维度**（编辑判断标准，不是填空）：
   - 信号强度：为什么现在是热点/值得写（融资/收购/上市/政策/中标/合作/收缩/亏损…）。信号弱就写"信号偏弱，但…"。
   - 信息量：可查证的公开信息（数据/财报/营收/用户量/专利/临床/门店数/融资额…）。
   - 差异化：和别家哪里不同（模式/壁垒/黏性/定位/首创/高频…）。
   - 可复制：国内创业者怎么借鉴（可复制/借鉴/国内/对标/思路/打法可学…）。
   四者都要点到，分散在一段话里即可，不必每句全中。
6. **禁重复企业名**（列表已显示企业名）：推荐理由里**不要再写企业名**，直接说事。
7. **禁与其他字段雷同**：不与 `desc_cn`、投融资字段等整句抄。列表共用一套基础信息，重复是浪费空间。
8. **大白话、禁技术黑话**（小爽是小白）：出现"血脑屏障/CNS/并购补管线/MODEL递送/按人头付费绑定医保结余/CDD自治"等，必须换成大白话或加 4 字内短解释。纯废话（赋能/一站式/全生命周期/组合拳/底层逻辑/抓手）一律删。
9. **禁绝对化"国内空白"论断**（教训④）：写前先看源文件里的 `domestic_competitors`：
   - 若**非空**：说"国内已有类似（X、Y）"或点出差异；
   - 若**为空**：说"国内竞品较少"（绝不说"空白/缺乏/尚无"）。
   查国内信息=看库内竞品（已预计算）+ 必要时 1 次联网确认，**不要凭印象下绝对结论**。
10. **desc_cn ≥ 80 字**：写清它干什么、商业模式/收入来源、银发价值。有商业信息量，不以"是一家/致力于/专注于"开头。
11. **silver_reason ≥ 30 字**：说清为什么判它核心银发/泛医疗擦边/非银发，给依据（参考 tag_l1/tag_l2 与银发信号）。

> 支付方规范词表（payor_model 必选其一）：
> 个人自费 / 个人自费+政府补贴 / 个人自费+长护险 / 个人自费+医保 /
> B端机构采购 / B端机构采购+政府付费 / B端机构采购+政府/商保支付 /
> 政府医保/商保支付 / 混合支付 / 不适用（投资机构） / 未搜到

## 六、自校循环（强制，不过不许交付）

每写完一个 `draft_#XXXX.json`，在 `scores_draft/rework/` 目录运行：
```
python check_single.py draft_#XXXX.json
```
- 输出 `PASS` → 才可交付。
- 输出 `FAIL:[...]` → 逐条读问题，**改到 PASS 再写下一个**。例如：
  - `R-name` → 删掉企业名；
  - `R-noabs` → 把"空白/缺乏"改成"国内竞品较少/已有类似(X)"；
  - `R-jargon` → 把黑话换成大白话；
  - `R-dedup` → 别整句抄 desc_cn；
  - `R5 缺维度-信号` → 补一句"近期中标/获投/政策…"。
**所有草稿必须 PASS 才结束。** 门禁是机器强制，不是建议。
