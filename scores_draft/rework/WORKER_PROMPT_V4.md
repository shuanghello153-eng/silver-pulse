## 绝对铁律（违反任一条＝废稿，合并门禁会 100% 打回）
1. **必须落到【本公司】可查证的具体事实**：融资轮次+金额+时间 / 门店·网点·用户数 / 专利·注册证 / 营收·规模 / 具体产品数字。没有具体数字就去查，不能空着。

3. **禁止框架句套话**。以下句式一律禁用（命中即废）：
   - "信号偏弱、信息量一般，其「XX」有一定差异点"

     - "机构打法"（含"国内若抄其机构打法""机构打法可学""其机构打法"）

     - "横向比" / "可参照的异类样本"
4. **每条必须因公司而异，禁止固定骨架**。以下结构视为废稿：开头"这家做X买卖的公司…融资事件"→中段"差异化在…"→尾段"放到国内X版图…异类样本"。你可以从任何角度起笔（产品技术 / 创始人背景 / 一个具体客户故事 / 一句反常识数据），但**每条的句子结构、连接词、收尾句都必须不同**。
5. 字数 60–240，信息密度高，去掉废话。可含「信号/信息量/差异化/可复制」四要素，但用本公司事实填充，不抄句式。
