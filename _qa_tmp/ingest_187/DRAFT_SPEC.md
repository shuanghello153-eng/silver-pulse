## 铁律（违反=返工）
1. **禁止编造**：融资金额/年份/投资方查不到就写"未披露"/"未搜到"。输入 funding_raw/business/research_value_raw 已是信源AI研究过的成果，**以输入信息为主直接转化**即可，不必逐家联网。仅当某家是知名上市公司、且输入信息明显不足时，才用 WebSearch 补 1~2 条关键事实（控制每家最多 1 次搜索，避免任务过重）。查不到一律"未披露/未搜到"，绝不猜。
2. **description**：中文为主（中文占比>30%，尽量全中文）、≥20字、只写事实（做什么/服务谁/怎么赚钱）。禁"是一家致力于/专注于为老年"开头。
3. **recommend**：不出现企业名本身；不复述 description 的事实和融资数字；写"为什么值得写"的判断。
   **禁用词（命中即毙，务必避开）**：值得关注/值得一写/值得跟踪/可成选题/深度案例/对标样本/异类样本/研究价值/信号偏弱/信号清晰/信号尚可/信号足/选题可写/可写「/拆开看/照搬难/暂列观察/机构打法/横向比/放到国内XX版图/按本土合规重新设计/切入XX赛道/可作为选题储备/归档备用/累计融资约$（正则）/赋能/一站式/全生命周期/组合拳/底层逻辑/抓手/闭环生态/链路/价值医疗/VBC/PBM/HMO/DRG/B2B2C/SaaS化/国内缺乏/市场空白/国内尚无/完全空白/尚无竞品。
   绝对化论断禁用（"国内没有/一片空白"），改说"国内同类形态尚少见"这类留余地表述。
4. **tag_l2 只能从下方词表选**，选最贴近业务的1~3个。
5. 评分要有区分度，别全打7。上市大公司 info 高；商业模式平平的 diff 给4-5；美国Medicare强绑定的 copy 给4-6（支付方差异大），日本介护险企业 copy 可给7-8（制度近似）。
6. 每家之间 recommend 措辞避免雷同句式（R10跨企业雷同门禁）。
