## ③ 整体准确性评分：中
抽样 80 家，明确错分约 8 家（~10%）、边界存疑约 5 家。一级框架与二级映射总体自洽，绝大多数（尤其养老服务/康复辅具/金融保险/产业资本主体）准确。主要问题集中在三类：
1. **描述与标签字面脱节**（joyforall、GoGoGrandparent、SetPoint、AARP Labs）——明显错分，应修正；
2. **跨域企业被塞入不符的二级**（问岐健康"药品"、Jona"营养食品"、唯艾"零售"）——二级标签过宽或关键词误命中；
3. **模板化空描述**（多家渠道零售/文娱条目 description 为"行业服务商"套话），导致标签不可从文本核验，建议补全真实业务描述。

建议优先修正 ① 中 8 家明确错分，并对"行业服务商"类条目的 description 回填实际业务，以提升可审计性。
