## 0. 目标与原则
- 标签**细致、细分**（有独特性价值），但**单二级企业数不宜过多**（预警 >100）；也不宜过碎（管理困难）。
- 二级标签只能属 1 个一级（L2_TO_L1 单归属硬规则）。
- 企业最多 3 个二级标签（规则B ≤3 截断）。
- tag_l1 由 tag_l2 经 L2_TO_L1 推导，企业不直接挂一级。
- 0 标签企业 = 0。

### 2.5 保险 vs 保险科技 去重
- `保险`=传统保险业务/承保方；`保险科技`=以科技做保险的创新公司。
- 若同一企业同时被标 `保险`+`保险科技` 且实质只属其一 → 去重，仅留最贴切的一个。
- 二者均属 金融保险 L1，允许企业跨二级（但≤3 上限）。

## 3. 再分配规则（按桶，KEYWORD 优先序；子智能体读 description 判定）

### 3.1 健康管理 + 健康监测 成员 → 新 L2
对原 `健康管理` 与 `健康监测` 的每一家企业（按 description 关键词，命中即归，优先级自上而下）：
1. 跌倒 / 防跌倒 / fall / PERS(跌倒) → `跌倒监测`
2. 用药 / 药盒 / 服药 / medication / adherence / 依从 → `用药管理`
3. 慢病 / 糖尿病 / 高血压 / chronic / 慢病管理 → `慢病管理`
4. 睡眠 / sleep / 睡眠监测 → `远程监测`（睡眠归入远程监测）
5. 远程监测 / RPM / 远程患者 / 体征 / vitals / 监测（非上述）→ `远程监测`
6. 体检 / 筛查 / 早筛 / screening / checkup / 检测服务 → `体检筛查`
7. 问诊 / 健康管家 / 健康教练 / telehealth / 健康咨询 / 健康管理服务 / wellness / 科普 → `健康咨询`
8. 残差（仍偏健康设备但无上述关键词）→ `远程监测`；偏服务 → `健康咨询`。**不得**回流到已删除的 `健康管理`/`健康监测`。

### 3.2 文化娱乐 成员 → 再分配
- 已知 14 家医疗/AI 错标（见 §4.1）→ 移出其真实 L2（AI/医疗健康/健康咨询等）。
- 行业媒体成员（AgeClub/ITH康养家/养老福祉圈/小咖云/SuperAging News/SeniorHousingLiving/SeniorSafetyAdvice/Caregiver Media Group/AARP/Aging2.0/SeniorPlanet 等）→ `行业服务`(行业媒体)
- 咨询研究成员 → `行业服务`(咨询研究)
- 社交平台类（软件/App/社区平台）→ `社交平台`
- 陪伴机器人 → `陪伴机器人`
- 旅游/健身/教育/相亲/就业 → 保留
- 线下社交**服务/社群/俱乐部/代际项目**（非平台）→ `社交`（新）
- 残差文娱内容/活动 → `社交平台` 或 `社交`（按是否平台判定）

### 3.3 人工智能(→AI) 非 AI 成员移出
- 真实 LLM/ML/CV/语音AI/大模型/AI 代理 → 保留 `AI`。
- 名称含 AI 但实质是医疗设备/电信/硬件 → 按真实业务再分配（如医疗器械/智能硬件/远程医疗）。
- 子智能体逐家读 description 判定；凡保留的 `AI` 必须确有 AI 技术属性。

### 3.4 居家护理 剔除非居家/非护理
- 陪诊服务 → `陪诊`（医疗健康）或 `健康咨询`
- 行业服务商/信息类 → `行业服务`
- 社交/娱乐误标 → `社交`/`社交平台`
- 纯产品公司误标 → 对应产品 L2（如 日用/个护）
- 其余真实"上门/家庭护理/居家照护" → 保留 `居家护理`

### 3.5 康复设备 拆分
- 外骨骼 / exoskeleton / 神经康复机器人 → `康复机器人`
- 轮椅 / wheelchair / 助行 / walker / 移位 → `行动辅具`
- 假肢 / prosthetic / 矫形 / orthotic → `假肢矫形`
- 护理床 / bed / 升降 / lift / 转移机 → `护理床具`
- 残差（通用康复辅具/无障碍辅具/未明设备）→ `康复设备`

## 5. 平台 / 社交 / 智慧养老 / 数字平台 关系界定（用户提问，明确结论）
- **平台（新, 养老服务）**：双边聚合/对接平台（连接老人家属↔服务商/商品）。例：照护匹配平台、养老服务商城。
- **智慧养老（原智能养老平台, 养老服务）**：面向养老运营方的**技术系统/SaaS/IoT**（机构管理、照护运营）。
- **照护系统（智能科技）**：护理交付软件/临床协调系统（ToB 软件）。
- **数字平台（智能科技）**：广义养老科技/IoT 技术平台；清理掉吞入的媒体/电商/类比公司后保留真技术平台。
- 四者**不合并**：平台=市场匹配、智慧养老=运营技术、照护系统=护理软件、数字平台=技术中台。若某成员同时贴合两个，按主营选其一（≤3 上限）。
