## 3. 再分配规则（reclassify 函数，按 description 关键词，命中即归，优先级自上）

### 3.1 健康管理 + 健康监测 → 新 L2
1. 跌倒/防跌倒/fall/PERS(跌倒) → 跌倒监测
2. 用药/药盒/服药/medication/adherence/依从 → 用药管理
3. 慢病/糖尿病/高血压/chronic/慢病管理 → 慢病管理
4. 睡眠/sleep/睡眠监测 → 远程监测
5. 远程监测/RPM/远程患者/体征/vitals/监测(非上述) → 远程监测
6. 体检/筛查/早筛/screening/checkup/检测服务 → 体检筛查
7. 问诊/健康管家/健康教练/telehealth/健康咨询/健康管理服务/wellness/科普 → 健康咨询
8. 残差：偏设备 → 远程监测；偏服务 → 健康咨询。不得回流已删标签。

### 3.2 文化娱乐 → 再分配（社交 vs 社交平台 按 Claude 边界表）
- 已知 14 家医疗/AI 错标（§4.1）→ 真实 L2
- 行业媒体成员 → 产业资本(行业媒体)
- 咨询研究成员 → 产业资本(咨询研究)
- 核心价值=内容（课程/视频/音乐/演出）→ 旅游/教育/健身/陪伴机器人 按内容类型；纯内容无更贴切者 → 社交平台
- 核心价值=社交图谱（匹配/社群/连接人）→ 社交平台
- 陪伴机器人 → 陪伴机器人
- 旅游/健身/教育/相亲/就业 → 保留
- 残差文娱 → 社交平台
- 不单建「社交」L2（按用户决策⑥）

### 3.3 人工智能(→AI) 非 AI 移出
- 真 LLM/ML/CV/语音AI/大模型/AI代理 → 保留 AI
- 名称含 AI 但实质医疗设备/电信/硬件 → 按真实业务再分配（医疗器械/智能硬件/远程医疗等）
- 逐家读 description 判定；保留的 AI 必须确有 AI 技术属性

### 3.4 居家护理 剔除非居家/非护理
- 陪诊服务 → 健康咨询
- 行业服务商/信息类 → 产业资本(行业媒体/咨询研究) 或 健康咨询
- 社交/娱乐误标 → 社交平台
- 纯产品公司 → 对应产品 L2（日用/个护等）
- 真实上门/家庭护理/居家照护 → 保留 居家护理

### 3.5 康复设备 拆分
- 外骨骼/exoskeleton/神经康复机器人 → 康复机器人
- 轮椅/wheelchair/助行/walker/移位 → 行动辅具
- 假肢/prosthetic/矫形/orthotic → 假肢矫形
- 护理床/bed/升降/lift/转移机 → 护理床具
- 残差（通用康复辅具/无障碍辅具）→ 康复设备

### 3.6 照护系统 + 智能养老平台 → 智慧养老
- 二者均整体替换为 智慧养老

### 3.7 数字平台 → 再分配
- 行业媒体(AgeClub等) → 产业资本(行业媒体)
- 电商/零售(亚马逊/京东类) → 渠道零售(电商)
- 真正 B2B 养老 SaaS/技术中台 → 智慧养老
- 电视购物(东方购物) → 渠道零售(零售)
- 类比公司(网飞/葫芦/Wayfair/Coinbase) → 按真实行业（文娱社交/渠道零售/金融保险）

### 3.8 精神健康(一级) + 女性健康(一级) 降级
- 精神健康成员 → 医疗健康 + 心理健康服务
- 女性健康成员 → 医疗健康 + 女性健康服务 / 更年期（按描述：更年期相关→更年期，其余→女性健康服务）
